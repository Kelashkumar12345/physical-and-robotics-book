# Welcome to Physical AI & Humanoid Robotics

Welcome to the comprehensive 13-week course on Physical AI and Humanoid Robotics. This hands-on program bridges the gap between artificial intelligence and physical embodiment, preparing you to build intelligent robotic systems that perceive, reason, and interact with the real world.

## Course Overview

This course is structured into four progressive modules spanning 13 weeks:

**Module 1: Foundations (Weeks 1-3)**
Build a solid foundation in ROS 2, simulation environments, and core robotics concepts. You'll set up your development environment and learn to work with both simulated and physical robots.

**Module 2: Perception & Vision (Weeks 4-6)**
Master computer vision and perception systems, including camera calibration, depth sensing, object detection, and pose estimation. Learn to process visual data for robotic applications.

**Module 3: Motion & Control (Weeks 7-9)**
Explore kinematics, dynamics, trajectory planning, and control systems. Implement motion planning algorithms and learn to control multi-degree-of-freedom robotic systems.

**Module 4: Intelligence & Integration (Weeks 10-13)**
Integrate AI models with robotic systems, implement reinforcement learning for manipulation tasks, and build complete autonomous systems. Culminate in a capstone project demonstrating end-to-end physical AI capabilities.

## Learning Outcomes

By the end of this course, you will be able to:

- Design and implement robotic systems using ROS 2 and modern robotics frameworks
- Develop perception pipelines for object detection, tracking, and pose estimation using computer vision and deep learning
- Apply kinematics, dynamics, and control theory to plan and execute robot motions
- Integrate large language models and foundation models with physical robotic systems
- Implement reinforcement learning algorithms for robotic manipulation and navigation tasks
- Deploy AI models on edge computing platforms for real-time robotic applications
- Build complete autonomous systems that combine perception, planning, and control

## Prerequisites

To succeed in this course, you should have:

- **Programming**: Basic proficiency in Python (variables, functions, classes, libraries)
- **Operating System**: Familiarity with Linux/Ubuntu command line (navigation, file operations, package management)
- **Mathematics**: Understanding of linear algebra (vectors, matrices) and basic calculus
- **Optional**: Prior exposure to robotics concepts or AI/ML fundamentals is helpful but not required

## Course Structure

Each week includes:

- **Theory Sessions**: Core concepts, algorithms, and design patterns
- **Hands-on Labs**: Practical exercises in simulation and on hardware
- **Assignments**: Weekly tasks to reinforce learning
- **Code Examples**: Production-ready implementations and templates
- **Resources**: Curated readings, papers, and additional materials

The course emphasizes practical, hands-on learning with immediate application of concepts to both simulated and physical robotic systems.

## Getting Started

Before diving into Module 1, ensure you have:

1. Reviewed the [Hardware Requirements](./hardware/requirements.md) and prepared your development environment
2. Installed Ubuntu 22.04 LTS (native or dual-boot recommended)
3. Verified your GPU drivers and CUDA installation (if using NVIDIA GPU)
4. Familiarized yourself with the course repository structure
